# UNIext — лендинг расширения UNI

Одностраничный сайт расширения **UNI — Roblox, но лучше**.
Статика без сборки: GitHub Pages отдаёт файлы прямо из ветки `main`.

## Структура

```
index.html              страница (RU по умолчанию, переключатель RU/EN)
404.html                страница ошибки
assets/                 иконка и скриншоты
downloads/              ZIP-сборка расширения
```

## Локальный просмотр

Открыть `index.html` файлом или поднять статику:

```powershell
python -m http.server 8000
# http://127.0.0.1:8000
```

## Публикация

```powershell
git add -A
git commit -m "site: update"
git push
```

GitHub Pages настроен на `main` / `/` — изменения выкатываются в течение минуты
на https://rouni.github.io/UNIext/

## Обновление сборки

1. Положить новый архив в `downloads/` и удалить старый.
2. Заменить `downloads/UNI-2.7.3-plus.zip` во всех ссылках (шапка, hero, подвал),
   версию в `.btn-note` (`v2.7.3-plus · 4.0 MB`) и в подвале `GPL-3.0 · v2.7.3-plus`.
3. Обновить номер версии в `.manual`-примечании, если он там встречается.
4. `git add -A; git commit; git push` — Pages пересоберётся сам.

## Анимации

- фон: три размытых фиолетовых блоба в `.bg` (keyframes `blob-a/b/c`) + шум через SVG-фильтр;
- кинетическая лента `.kinetic`: два ряда по `[data-marquee]`, текст собирается в JS
  (`renderMarquee`) и пересобирается при смене языка; движение — `drift-a` / `drift-b`
  с `alternate`, то есть «туда-сюда»;
- появление секций: `[data-reveal]` + IntersectionObserver, задержки в nth-child;
- кнопки-пилюли: `.btn-primary` залит градиентом, при наведении едет блик `::after`;
- у карточек при наведении подсвечивается точка под курсором (`--mx` / `--my`);
- `prefers-reduced-motion: reduce` выключает всё это, контент показывается сразу.

## Язык

Тексты лежат в атрибутах `data-ru` / `data-en`. Переключатель — `#lang`.

Порядок выбора при загрузке:

1. `?lang=ru` или `?lang=en` в адресе — принудительно;
2. сохранённый ручной выбор в `localStorage` (`uni-site-lang`);
3. **по умолчанию английский**; русский включается сам, только если IP-геолокация
   вернула `RU`, `UA`, `KZ` или `BY`. Запросы идут по цепочке
   `ipwho.is` → `get.geojs.io` → `api.country.is` (таймаут 2.6 с на каждый).
   Если все недоступны — смотрим `navigator.language` (`ru/uk/be/kk`).

Ручной выбор пользователя геолокацию перекрывает и сохраняется между визитами.
