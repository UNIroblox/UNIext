Features

Every feature has its own switch in the settings. Nothing is forced: tick it and it works.

  • Region picker

    Datacenter map with ping to each one: join the closest server instead of a random one.

  • Server list

    Online count, version and uptime for every server, filters, sorting, one-click join.

  • Trade values

    RAP, chances and market value right in the trade window — see whether you are overpaying.

  • Profile

    Avatar frames, notes, pronouns, hidden games and badges — make the profile yours.

  • Friends

    Labels for friends, who is in the same game, a detector for those who unfriended you.

  • Bulk actions

    Strip badge likes, leave groups, unfriend everyone — in bulk, not one by one.

  • Themes & looks

    Light and dark themes, custom backgrounds, free Roblox Plus themes and legacy UI on demand.

  • Quick search

    Search players, games and friends from the keyboard, anywhere on the site.

  • Private servers

    Bulk enable or disable servers, copy links, join through the closest region.

Install

Any Chromium browser: Chrome, Edge, Opera, Brave, Vivaldi. No store needed.

  1. Download the archive

    The “Download the plus build” button gives you UNI-2.7.3-plus.zip.

  2. Unpack it

    Into its own folder — the browser won't load it from inside the zip.

  3. Load into the browser

    Open chrome://extensions and click “Load unpacked”.

  4. Open Roblox

    The UNI panel sits in the site header, settings under the gear icon.

Chrome will warn that the extension isn't from the store — normal for a manual install, you can enable it.

Using a different browser?

Same steps, only the extensions page address changes:

  • Chromechrome://extensions
  • Edgeedge://extensions
  • Bravebrave://extensions
  • Operaopera://extensions
  • Vivaldivivaldi://extensions
  • Any otherChromium-based

Firefox and Safari don't run Chrome extensions — the build won't work there.

04

FAQ

Short answers.

Is it really free?

Yes. Every feature is free, with no subscription and no paid tiers. The project runs on donations: features like the region picker need servers, and servers cost money.

Why not from the Chrome Web Store?

The plus build ships as an archive, without store review: updates land immediately and nobody gets stuck on an old version. It installs manually via “Load unpacked”.

Is it safe?

The manifest only asks for Roblox domains and file downloads — no access to other sites. Chrome warns once that the build isn't from the store: expected for a manual install.

Where to report a bug?

The Telegram channel — link in the header and footer. Updates are announced there too.
